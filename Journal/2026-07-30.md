## Branch creation and exact location planning

- Code review confirmed that the current source already includes the Branches Add button/create modal and the protected create API. The likely user-facing blocker is a `manage_settings` permission mismatch or an outdated deployment, not an absent data model.
- The Branch schema already has nullable latitude/longitude. The requested address -> exact pin flow needs no database migration: extend create to persist an explicitly confirmed coordinate pair and reuse the existing Leaflet map editor.
- Planned scope: explicit address search, result selection, click/drag pin adjustment, coordinate preview, strict API validation, RBAC-aligned controls, and map/pin browser tests.
- Leaflet is suitable for this small internal MVP. Public Nominatim must not be used as client autocomplete; provider traffic, caching, identity, attribution, and switchability need an application-owned boundary before implementation.
- Full approved-planning candidate and remaining owner decisions: [[Planning/Pages/Branches]]. No code, schema, role, provider, or deployment change was made.

## Branch permissions and free map-pin implementation

- User approved role-configured Branch access and the free Leaflet + controlled Nominatim MVP.
- Added a dedicated `manage_branches` permission to the API, frontend permission keys, local seed data, and a versioned Supabase migration. The existing Roles screen automatically lists the option once the migration is applied; no role is granted it by default except the code-level SuperAdmin bypass.
- Add Branch now allows an authorized user to search an address through a controlled, cached, explicit-search API endpoint, choose a result, then click or drag the map marker before saving. Coordinates are optional and strictly validated as a complete latitude/longitude pair.
- Verified locally: API build; 133 Vitest tests passed, including coordinate validation tests; Svelte check completed with 0 errors (147 existing project warnings). No live Supabase migration, role assignment, external geocoder request, browser session test, deployment, or commit was performed.
